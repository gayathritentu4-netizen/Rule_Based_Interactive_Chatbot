# Rule-Based Interactive Terminal Assistant

## Project Description
A rule-based interactive chatbot developed using Python. It recognizes user greetings and multiple FAQ intents using regular expressions and provides suitable responses from a JSON dataset.

## Technologies Used
- Python 3
- Jupyter Notebook
- Regular Expressions (re)
- JSON

## Features
- Greeting recognition
- Business hours information
- Internship project submission details
- Certificate information
- Multiple intent recognition
- Fallback responses for unknown questions
- Exit commands (bye, exit, quit)

## Project Files
- `Rule_Based_Chatbot.ipynb` – Main chatbot implementation.
- `sample_faq.json` – FAQ questions, answers and greetings.

## How to Run
1. Install Python and Jupyter Notebook.
2. Download or clone this repository.
3. Keep both project files in the same folder.
4. Open Jupyter Notebook.
5. Open `Rule_Based_Chatbot.ipynb`.
6. Run all cells.

Successfully developed and tested an interactive rule-based student support chatbot using Python and JSON.
